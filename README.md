# NEON SNAKE — Full Arcade Edition

A standalone GitHub Pages-ready Snake game built with HTML5, CSS3 and vanilla JavaScript.

## Files
- index.html
- style.css
- script.js

## Included
WASD + arrow controls, mobile D-pad, Classic/Time Attack/No Walls/Hardcore/Zen/Challenge modes, coins, shop, skins, board styles, themes, power-ups, obstacles, missions, achievements, local top-10 leaderboard, combo, XP/player levels, daily challenge/streak, stats, trail, screen shake, Web Audio effects, save export/import and localStorage persistence.

## Deploy
Upload the three main files to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from branch.

No server or backend is required.
